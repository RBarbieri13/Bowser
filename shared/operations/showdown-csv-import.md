# Supplied Showdown projection imports

Use `python3 scripts/import_showdown_csv.py <supplied-csv> --slate <dated-slate-key>` in an isolated checkout of latest verified main. `--dry-run` validates without writes. The selected full-game Showdown must be unlocked; the filename must identify the selected DraftKings slate. Every FLEX player must appear exactly once and match normalized name, team, position, opponent, and official FLEX salary. Reject missing/duplicate players, salary mismatches, wrong games, invalid numbers and post-lock imports.

The CSV's `fpts` replaces the selected slate's projection values only. Blank values are null, including players previously projected by other providers. A numeric zero remains zero. CPT derives exactly 1.5 times FLEX; existing role salaries and stable identities are unchanged. Ownership, ceilings/floors, exposure settings and other CSV fields are not imported by this projection-only workflow. Export/publication time is unavailable unless present in a separately verified source; capture time is labeled as import time.

Preserve the original attachment outside Git under `inbox/dfs-projection-imports/<date>/` with private filesystem permissions. Snapshot lineage stores only filename, hash, source format and import clock. No credentials, raw user exposure settings or league material belong in public data. The provider URL is attribution; it does not imply an automated source download.

The importer reuses weekly validation and atomic JSON/archive publication. It appends a capture, retains prior captures, leaves other slates and the weekly Classic default unchanged, and no-ops on the same file hash. A later ordinary pregame source refresh can supersede the current capture; the manual capture remains selectable in history. Locked slates are excluded from normal refresh.

Before release, run `python3 scripts/import_dfs_weekly.py --verify`, `npm run check`, `npm run lint`, and independent read-only review. Verify all supplied numeric values and nulls in both roles, unchanged salaries, unchanged other slates and exact preservation of every previous archive row. Use the normal branch/PR/candidate-verification/exact-head-merge workflow and read back the selected slate on both permanent aliases. Bound the run to two hours and stop after three repeated correction failures. Never weaken validation or substitute old projections for source blanks.
