# Shared fantasy-football resources

Use this area for material that applies across two or more leagues.

- [`research/`](research/) — player, team, injury, coaching, and schedule research.
- [`rankings/`](rankings/) — dated cross-league rankings and tiers.
- [`tools/`](tools/) — scripts, calculators, prompts, and reusable workflows.
- [`templates/`](templates/) — standardized league profiles and analysis formats.
- [`data/`](data/) — cross-league data-source manifests and warehouse provenance.

Every recommendation must still state which league settings it assumes.
