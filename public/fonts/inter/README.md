# Inter for player-card numbers

Unmodified Inter Semibold (600) and Bold (700), retrieved October 28, 2026 from the official Google Fonts stylesheet:
https://fonts.googleapis.com/css2?family=Inter:wght@500;600;700&display=swap

- Semibold: https://fonts.gstatic.com/s/inter/v20/UcCO3FwrK3iLTeHuS_nVMrMxCp50SjIw2boKoduKmMEVuGKYMZg.ttf
- Bold: https://fonts.gstatic.com/s/inter/v20/UcCO3FwrK3iLTeHuS_nVMrMxCp50SjIw2boKoduKmMEVuFuYMZg.ttf
- License: https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt (included as OFL.txt)

The CSS family alias `Bowser Inter` scopes the locally served files to individual player cards and avoids relying on an installed font or an external runtime font request. Both files contain tabular lining numerals; the player card requests them with `font-variant-numeric`.
